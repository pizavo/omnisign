## Opening documents

The toolbar picker is not the only route into the viewer. Every installer registers OmniSign as a
handler for PDF files, so it also appears in the system's **Open with** menu; a document chosen
there — or double-clicked, once OmniSign is the default PDF application — loads straight into the
viewer with no further steps.

Registering a handler is not the same as becoming the default. Which application owns `.pdf` stays
a per-user choice on every platform, and
[Installation](installation.mdx#pdf-file-association) covers how to set it.

On macOS the document is handed to the OmniSign window that is already open. On Windows and Linux
it always starts a new window, so opening a document this way while OmniSign is running leaves the
first window untouched.
