## Prerequisites

The native installers bundle their own Java runtime, so **no separate Java
installation is required** to run OmniSign CLI. Java is only needed if you use
the fat JAR distribution or run from source.

<OsTabs>
<TabItem value="windows" label="Windows">

A Java runtime is bundled with the MSI installer. To run the fat JAR, install
**Java 25** or newer from [Adoptium](https://adoptium.net/) or via winget:

```powershell
winget install EclipseAdoptium.Temurin.25.JDK
```

</TabItem>
<TabItem value="linux" label="Linux">

A Java runtime is bundled with the DEB/RPM package. To run the fat JAR, install
**Java 25** or newer via your package manager:

```bash
# Debian / Ubuntu
sudo apt install temurin-25-jdk

# Fedora / RHEL
sudo dnf install temurin-25-jdk
```

</TabItem>
<TabItem value="macos" label="macOS">

A Java runtime is bundled with the DMG installer. To run the fat JAR, install
**Java 25** or newer via Homebrew:

```bash
brew install --cask temurin@25
```

</TabItem>
</OsTabs>

## Install OmniSign CLI

<OsTabs>
<TabItem value="windows" label="Windows">

**Option A — MSI installer**

Download `omnisign-cli-x.y.z.msi` from
[GitHub Releases](https://github.com/pizavo/omnisign/releases) and run it. You can install either
for the current user (no administrator rights, under `%LOCALAPPDATA%`) or system-wide (elevated,
under `Program Files`); the installer adds the install directory to the matching `PATH`, so
`omnisign` is available from any new terminal.

The files go into an `omnisign-cli` subdirectory of whichever location you choose, and the package
carries its own upgrade code, so the CLI and the desktop app are independent and can be installed
side by side in either order.

**Option B — Fat JAR**

```powershell
java -jar omnisign-cli.jar --help
```

</TabItem>
<TabItem value="linux" label="Linux">

**Option A — DEB package**

```bash
sudo dpkg -i omnisign-cli_x.y.z_amd64.deb
```

**Option B — RPM package**

```bash
sudo rpm -i omnisign-cli-x.y.z.x86_64.rpm
```

**Option C — Fat JAR**

```bash
java -jar omnisign-cli.jar --help
```

</TabItem>
<TabItem value="macos" label="macOS">

**Option A — PKG installer**

Download `omnisign-cli-x.y.z.pkg` from
[GitHub Releases](https://github.com/pizavo/omnisign/releases) and run it. It installs to
`/Applications/omnisign-cli/`, symlinks the launcher to `/usr/local/bin/omnisign` so the command is
on your `PATH`, and writes an `omnisign-uninstall` script alongside it.

**Option B — DMG installer**

Download `omnisign-cli-x.y.z.dmg` from
[GitHub Releases](https://github.com/pizavo/omnisign/releases) and drag the app bundle to the
`omnisign-cli` folder it offers. The DMG copies the files but does not create the `/usr/local/bin`
symlink, so invoke the launcher by its full path or add one yourself:

```bash
sudo ln -sf /Applications/omnisign-cli/omnisign.app/Contents/MacOS/omnisign /usr/local/bin/omnisign
```

Both installers keep the CLI in its own `/Applications/omnisign-cli/` folder rather than beside the
desktop app's `/Applications/OmniSign.app`, so the two can be installed side by side.

**Option C — Fat JAR**

```bash
java -jar omnisign-cli.jar --help
```

</TabItem>
</OsTabs>
